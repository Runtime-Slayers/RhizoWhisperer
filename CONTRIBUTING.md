# Contributing to RhizoWhisperer

We welcome contributions from researchers, agronomic software engineers, and plant phenotyping developers!

## How to Contribute

1. **Fork the Repository**: Create your feature branch (`git checkout -b feature/amazing-feature`).
2. **Commit Your Changes**: Follow clear commit message guidelines (`git commit -m 'Add new GNN attention module'`).
3. **Push to Branch**: (`git push origin feature/amazing-feature`).
4. **Open a Pull Request**: Submit your pull request to `Runtime-Slayers/RhizoWhisperer`.

## Code Style & Testing
- Ensure Python code adheres to PEP 8 standards.
- Run unit tests before submitting PRs:
  ```bash
  pytest tests/
  ```
